Cinzel and Inter variable fonts, Latin subset, supplied locally so startup never
depends on Google Fonts being reachable. German characters are included.

Source: `@fontsource-variable/cinzel@5.3.0` and
`@fontsource-variable/inter@5.3.0`, `files/*-latin-wght-normal.woff2`.
